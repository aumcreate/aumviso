# AumViso – AI SEO & GEO: Schema, Sitemaps & Internal Links

An all-in-one SEO and GEO toolkit that manages your meta tags, Schema, sitemaps and internal links, and can draft content with AI.

- **WordPress.org:** https://wordpress.org/plugins/aumviso/
- **Website:** https://aumcreate.com
- **Support:** support@aumcreate.com

## About this repository

This is the released source of the plugin, exactly as published on WordPress.org — one commit per release, tagged with the version. Bug reports and pull requests are welcome here; fixes are folded into the next release.

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for *AumViso – AI SEO & GEO: Schema, Sitemaps & Internal Links*), or download a release from this repository's tags and upload the ZIP.
